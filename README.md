# Student CRM

Учебный React-проект для отображения списка студентов.

## Функционал

- отображение списка студентов;
- передача данных через `props`;
- отображение статуса обучения;
- подсчёт общего количества студентов;
- условное отображение сообщения для несовершеннолетних;
- сообщение при пустом списке.
